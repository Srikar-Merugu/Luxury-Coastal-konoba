# Brand fonts (licensed, not included)

Put the purchased **web** font files here, named exactly:

- `TanMonCheri.woff2` – Tan Mon Cheri (titles, hero arc, nav)
- `GoldenHopes.woff2` – Golden Hopes (handwritten script lines)

Restart `npm run dev` (or redeploy). The site switches to them automatically;
without them it uses Poiret One and Sacramento from Google Fonts.
Only use files you hold a web licence for.
